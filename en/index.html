Privacy Policy for Sternensammler

In short

Sternensammler sends nothing. The app has no internet permission — it cannot send anything, not even by accident. Everything entered stays on the device.

There is one exception, and it does not come from the app: Android backs up the data of installed apps into the user's Google backup if they have switched that on for their device. More on that below.

Which data does the app process?

Stored on the device is only what parents enter themselves:

  • The children's first names and the chosen animal picture. A first name is enough; the app does not ask for a surname, a date of birth or a photo.
  • Tasks with their star value.
  • Completions — which task was ticked off on which day.
  • Rewards and when which child redeemed stars for them.
  • An optional parent code that hides the parent area from the children — stored derived, not in clear text.

The app collects nothing by itself: no device identifier, no advertising ID, no location, no usage statistics.

The parent code is not stored in clear text, only a value derived from it. Anyone inspecting the app's storage cannot read it from there. > It still is what it is: four digits that keep children out of the parent area. It is not a password — anyone who has the derived value and is willing to try ten thousand possibilities will get there. So do not use a code you use anywhere else.

Where does this data go?

Nowhere — the app has no server, no user account, no synchronisation and no permission to go online.

The Android backup is switched on. That means: if backup to Google is enabled on the device, Android takes this app's data along — so the collected stars survive a change of device. That is done by the operating system, not by the app; the data then sits encrypted in the user's Google account and is subject to their terms. Anyone who does not want this switches the backup off in the Android settings (usually under "System → Backup").

The backup you create yourself

In the parent area everything can be saved as a file. You decide where it goes: the device opens its share dialogue, and the file goes wherever you send it — into an email to yourself, into a cloud, into the device's storage.

The app itself sends nothing. It puts the file into its own cache and hands it to the dialogue; it needs no permission for that.

⚠️ What you pass on is complete. The file contains the children's first names, their stars, tasks and rewards — and the derived value of the parent code. A backup in someone else's cloud sits under their terms, not ours.

Analytics, adverts, sharing

The app contains no analytics tool, no crash reporting SDK and no adverts. There are no purchases in the app. No data is passed on to third parties or sold.

The fonts, too, are part of the program itself. The app loads nothing from external servers — in particular no fonts from Google Fonts, which would otherwise send the device's address on every start.

Children

The app is meant for families: parents create children, tasks and rewards, children tick things off and see how they are doing. Nothing is collected and nothing is transmitted in the process either.

Permissions

The app requests no permissions. Not internet, not location, not camera, not microphone, not contacts, not storage.

Deletion

All data sits in the app's storage on the device. It disappears completely when the app is uninstalled or its storage is cleared (Android settings → Apps → Sternensammler → Storage → Clear data). Nothing is left behind, because there is nothing anywhere else.

If the Android backup was used, a copy remains there. It is deleted through the user's Google account settings.
